# NOTE — deliberately NO `Disallow: /api/`.
#
# The lineup islands fetch /api/lineup on mount, and a renderer that executes
# JavaScript (Googlebot does) indexes the DOM it ends up with. Blocking the
# endpoint means that fetch fails during rendering, and what gets indexed is
# whatever the page falls back to rather than the lineup. The pages now also
# pre-render the lineup into their HTML, but the crawl budget saved by hiding
# two CDN-cached JSON URLs is not worth putting that at risk.
#
# The post-conversion pages (/thank-you, /newsletter-subscription-thank-you)
# are not disallowed either: they carry `noindex`, and a crawler has to be
# allowed to fetch a page to see that.
